## 0. 题目到底在做什么

导弹以固定速度直飞假目标原点；无人机接到任务后可瞬时改变航向，随后以固定速度、等高度、直线飞行。无人机投下烟幕弹后，烟幕弹继承无人机水平速度并做自由落体；起爆后瞬时形成半径 10 m 的有效球状烟幕，烟幕中心以 3 m/s 匀速下沉，起爆后 20 s 内有效。

# 2. 可复用运动学函数

## 2.1 导弹轨迹

对任意导弹初始位置 \(M_0\)，单位飞行方向：

\[
e_M=-\frac{M_0}{\|M_0\|}
\]

因此：

\[
\boxed{M(t)=M_0+300e_Mt}
\]

导弹到达假目标时间：

\[
\boxed{t_{\rm hit}=\frac{\|M_0\|}{300}}
\]

程序接口建议：

```python
missile_position(t, M0)
missile_hit_time(M0)
```

---

## 2.2 无人机轨迹

设无人机初始位置：

\[
U_0=(x_0,y_0,z_0)
\]

水平航向角 \(\psi\) 从 \(+x\) 轴逆时针计算：

\[
e_U=(\cos\psi,\sin\psi,0)
\]

固定飞行速度 \(v\)，则：

\[
\boxed{
U(t)=U_0+vt(\cos\psi,\sin\psi,0)
}
\]

程序接口：

```python
uav_position(t, U0, speed, psi)
```

## 2.3 第 i 枚烟幕弹的投放点

投弹时刻 \(t_{d,i}\)：

\[
\boxed{
P_{d,i}=U(t_{d,i})
}
\]

## 2.4 第 i 枚烟幕弹的起爆点

令引信延迟为 \(\tau_i\)，则：

\[
t_{e,i}=t_{d,i}+\tau_i
\]

烟幕弹脱离无人机后继承无人机水平速度，仅受重力：

\[
\boxed{
P_{e,i}
=
\left(
x_0+vt_{e,i}\cos\psi,\ 
y_0+vt_{e,i}\sin\psi,\ 
z_0-\frac12g\tau_i^2
\right)
}
\]

这是整题非常重要的简化：

- 水平起爆位置主要由 \(t_e\) 决定；
- 起爆高度主要由引信延迟 \(\tau\) 决定。

必须保证：

\[
z_0-\frac12g\tau_i^2\ge0.
\]

## 2.5 起爆后的烟幕云轨迹

设：

\[
P_{e,i}=(x_{e,i},y_{e,i},z_{e,i})
\]

则在：

\[
t_{e,i}\le t\le t_{e,i}+20
\]

内：

\[
\boxed{
C_i(t)=
(x_{e,i},y_{e,i},z_{e,i}-3(t-t_{e,i}))
}
\]

不考虑水平风漂移，因为题面只规定云团中心以 3 m/s 匀速下沉。

# 3. 严格有效遮蔽判据

## 3.1 一个目标点是否被烟幕遮住

导弹位置 \(M(t)\)，目标点 \(X\)，烟幕中心 \(C(t)\)。

导弹到目标点的视线段：

\[
L(\lambda)=M+\lambda(X-M),\quad 0\le\lambda\le1.
\]

令：

\[
a=X-M,\qquad b=C-M.
\]

无约束投影参数：

\[
\lambda_0=\frac{a\cdot b}{a\cdot a}.
\]

裁剪在线段：

\[
\boxed{
\lambda^*=\min(1,\max(0,\lambda_0))
}
\]

烟幕中心到该视线段的最短距离：

\[
\boxed{
d(C,\overline{MX})
=
\|b-\lambda^*a\|
}
\]

若：

\[
d(C,\overline{MX})\le10
\]

则该目标点到导弹的视线穿过有效烟幕球。

核心程序：

```python
point_to_segment_distance(C, M, X)
```

# 4. 单烟幕：完整圆柱判据严格降维为上下两圆周

上下两条圆周参数化：

\[
\boxed{
X_h(\theta)=
(7\cos\theta,\ 200+7\sin\theta,\ h)
}
\]

其中：

\[
h\in\{0,10\},\qquad 0\le\theta<2\pi.
\]

单个球状烟幕从导弹位置形成的“后方遮蔽域”为凸集；而整个实心圆柱恰好是上下两个圆周的凸包。因此：

\[
\boxed{
\text{完整圆柱被单烟幕遮蔽}
\iff
\text{上下两个圆周的所有点均被遮蔽}
}
\]

于是定义：

\[
\boxed{
D_i(t)=
\max_{h\in\{0,10\},\theta\in[0,2\pi)}
d(C_i(t),\overline{M(t)X_h(\theta)})
}
\]

单烟幕完全遮蔽：

\[
\boxed{D_i(t)\le10}
\]

这就是 Q1、Q2 的正式主判据，也可作为 Q3~Q5 的“单烟幕快速判据”。

数值实现建议：

1. 先在 \(\theta\) 上均匀粗采样；
2. 找最大距离附近候选角；
3. 对候选角用 `scipy.optimize.minimize_scalar` 做一维局部极值精修。

程序：

```python
max_ring_distance(...)
full_target_margin(t, ...)
```

其中：

```text
margin = D(t) - 10
margin <= 0  → 完全遮蔽
margin > 0   → 未完全遮蔽
```

# 5. 时间区间计算

对单枚烟幕，仅在：

\[
[t_e,\min(t_e+20,t_{\rm hit})]
\]

中研究：

\[
F(t)=D(t)-10.
\]

流程：

1. 粗时间扫描；
2. 找 \(F(t)\) 符号变化；
3. 用 `scipy.optimize.brentq` 精确求根；
4. 得到所有 \(F(t)\le0\) 的时间区间。

程序建议：

```python
single_smoke_intervals(...)
```

**不要假设单烟幕遮蔽区间一定只有一个连续段**；接口应返回区间列表。

# 7. 多烟幕“拼图式”联合遮蔽：严格模型

单个烟幕的遮蔽域是凸的，但多个烟幕遮蔽域的并集通常不是凸集，因此：

> 多烟幕联合遮蔽时，“只检查上下两圆周即可推出整个目标都遮住”的凸性证明一般失效。

对目标可见表面/边界采样点 \(X_j\)，对每个有效烟幕 \(i\)：

\[
d_{ij}(t)
=
d(C_i(t),\overline{M(t)X_j}).
\]

某目标点只需要至少被一枚烟幕遮住：

\[
q_j(t)=\min_i d_{ij}(t).
\]

整个目标的最不利点：

\[
\boxed{
Q(t)=\max_j\min_i d_{ij}(t)
}
\]

联合完整遮蔽：

\[
\boxed{Q(t)\le10}
\]

建议 Q3~Q5 采用“两层策略”：

### 优化阶段（快）
各烟幕单独用上下两圆周严格判据，目标取单烟幕完整遮蔽时间的并集。

### 最终精检（严）
对最终候选方案用：

\[
\max_j\min_i d_{ij}(t)\le10
\]

做多烟幕联合覆盖精检。

定义协同增益：

\[
\boxed{
\Delta T_{\rm coop}
=
T_{\rm exact\ union}-T_{\rm independent\ union}
}
\]

若接近 0，说明主要是时间接力而非空间拼图；若明显大于 0，再把联合模型用于局部精修。

# 10. Q3：FY1 投 3 枚烟幕，对 M1

## 10.1 关键结构

三枚弹共享同一：

\[
\boxed{\psi,\ v}
\]

因为无人机一旦选定航向和速度就不能再改变。

每枚弹有：

\[
t_{d,i},\ \tau_i,\quad i=1,2,3.
\]

总计 8 个连续变量：

\[
(\psi,v,t_{d,1},t_{d,2},t_{d,3},\tau_1,\tau_2,\tau_3).
\]

同一无人机投弹间隔：

\[
t_{d,2}-t_{d,1}\ge1,
\]

\[
t_{d,3}-t_{d,2}\ge1.
\]

推荐无约束化参数：

\[
t_{d,1}=s_1,
\]

\[
t_{d,2}=s_1+1+s_2,
\]

\[
t_{d,3}=s_1+2+s_2+s_3,
\]

其中：

\[
s_1,s_2,s_3\ge0.
\]

这样投弹间隔天然满足。

## 10.2 主优化目标

对每枚弹求独立完整遮蔽时间集合 \(E_i\)：

\[
\boxed{
\max
\mu(E_1\cup E_2\cup E_3)
}
\]

不要强制三个遮蔽区间连续；题目允许不连续。

不要强制起爆顺序和投弹顺序相同；题目只约束投弹间隔。

## 10.3 求解策略

推荐：

```text
Q2 解作为初始启发
   ↓
粗搜航向 ψ、速度 v
   ↓
给定航线，优化 3 个投弹时刻 + 3 个延迟
   ↓
8 变量联合差分进化精修
   ↓
严格圆周判据复算
   ↓
多烟幕 max-min 联合覆盖精检
   ↓
写 result1.xlsx
```

可以用“新增遮蔽时间”贪心构造初值：

\[
\max |E_1|
\]

然后：

\[
\max |E_2\setminus E_1|
\]

再：

\[
\max |E_3\setminus(E_1\cup E_2)|.
\]

注意：Q2 的最优 \((\psi,v)\) 只适合作为 Q3 初值，不能锁死；“最适合一枚弹的航线”未必“最适合三枚弹接力”。

# 12. Q5：5 架无人机，每架最多 3 枚，对 M1/M2/M3

这是整题的大规模联合优化。

## 12.1 每架无人机的共享变量

无人机 \(j\) 一旦确定：

\[
(\psi_j,v_j)
\]

后，其最多三枚弹共享该航向和速度。

每架内部：

\[
t_{d,j,2}-t_{d,j,1}\ge1,
\]

\[
t_{d,j,3}-t_{d,j,2}\ge1.
\]

仍可使用 \(s\) 参数化自动满足间隔。

## 12.2 不一定要显式“把某枚弹分配给某枚导弹”

更通用的做法：

对每一枚导弹 \(M_k\)，都独立计算当前所有有效烟幕对它的遮蔽效果。

令导弹 \(k\) 的有效遮蔽时间集合为 \(E^{(k)}\)，推荐主目标：

\[
\boxed{
\max
\sum_{k=1}^{3}\mu(E^{(k)})
}
\]

这样某一团烟幕如果恰好能同时帮助两枚导弹，模型会自动计入，不需要预先人工指定“归属”。

为了降低搜索复杂度，可以在**快速优化阶段**先做启发式任务分配（某些弹优先服务某枚导弹），但最终评价最好采用“无硬分配”的统一判据。

## 12.3 分层求解建议

### 阶段 A：候选烟幕生成
对每架 UAV × 每枚 missile 做单弹/三弹局部优化，获得高质量候选。

### 阶段 B：任务分配 + 时间调度
决定：
- 哪架 UAV 主要服务哪枚 missile；
- 每架投几枚；
- 各投弹时刻、引信延迟。

可用：
- 差分进化；
- 粒子群；
- 遗传算法；
- 启发式贪心 + 局部搜索；
- 混合整数 + 连续搜索分层处理。

### 阶段 C：连续变量联合精修
在候选任务分配附近优化：

\[
\psi_j,\ v_j,\ t_{d,j,i},\ \tau_{j,i}.
\]

### 阶段 D：高精度最终验证
对每枚导弹分别：
- 精确时间边界；
- 目标表面更密采样；
- 多烟幕联合 `max-min` 判据。

最终计算：

\[
T_1,\ T_2,\ T_3,\quad T_{\rm sum}=T_1+T_2+T_3.
\]

输出 `result3.xlsx`。

# 14. 数值计算建议

## 14.1 两层精度

优化阶段：

```text
θ 步长：2°~5°
时间步长：0.05~0.10 s
```

最终复算：

```text
θ：粗网格 + 连续局部极值
时间边界：Brent 求根
多烟幕表面精检：更密 θ、z 网格
```

## 14.2 优化算法

目标函数包含：
- `max`
- 区间并集
- 布尔事件
- 可能的离散任务分配

因此往往非光滑、非凸，不应只依赖梯度法。

推荐：

```text
物理降维
→ 网格粗搜
→ differential_evolution / PSO / GA
→ 局部精修
→ 高精度复算
```

# 15. 多烟幕联合精检的目标采样

如果采用完整可见表面离散：

圆柱侧面：

\[
X(\theta,z)=
(7\cos\theta,\ 200+7\sin\theta,\ z)
\]

例如：

\[
\theta=0^\circ,1^\circ,\ldots,359^\circ

\[
z=0,1,\ldots,10.

最终验证可以加密到：

\[
\Delta\theta=0.25^\circ,\quad
\Delta z=0.25\ \mathrm m.

同时可以补上下底面内部采样，或直接构造“导弹视角下的可见表面”。

做网格收敛性：

```text
5° → 2° → 1° → 0.5° → 0.25°
```

观察最终遮蔽时长是否稳定。

# 16. 当前必须保持一致的建模假设

1. 重力加速度：
   \[
   g=9.8\ \mathrm{m/s^2}
   \]

2. 烟幕弹投放后只受重力，继承无人机水平速度。

3. 烟幕起爆后：
   - 水平坐标固定；
   - 云心只以 3 m/s 竖直下沉；
   - 不考虑风漂移；
   - 有效球半径 10 m；
   - 只在 20 s 内有效。

4. “有效遮蔽”主定义：
   - 单烟幕：整个真目标圆柱均在其遮蔽域中；
   - 用上下两圆周严格等价判据；
   - 多烟幕最终精检允许多团烟幕共同覆盖目标。

5. 对 Q3~Q5：
   - 快速优化可先用“单烟幕完整遮蔽区间并集”；
   - 最终必须检查多烟幕空间联合遮蔽是否产生额外协同时间。

6. Q2 当前结果为数值近优解，不写成“已解析证明全局最优”。
